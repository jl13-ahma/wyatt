# Campaign preparation

There is no live Wyatt Kickstarter campaign URL yet. This CAD-only release is an optional source and contribution resource; it is not a campaign, preorder or working-product demonstration.

A future campaign must stand on its own: show a working prototype and its current functionality, explain dependencies and distinguish demonstrated functions from planned development. Hardware/product-design rules require a working prototype and prohibit photorealistic product renderings. The native CAD technical views in this repository are engineering illustrations, not substitutes for real prototype footage. Planned cloud or local-computer chat must not be presented as demonstrated onboard AI.

GitHub may provide optional CAD/source files and a place for design suggestions or build reports. Campaign information, updates and backer replies should also remain on Kickstarter. Do not use a campaign to funnel engagement offsite or redirect pledges/orders elsewhere. See the official [Kickstarter rules](https://www.kickstarter.com/rules) and [hardware and product-design requirements](https://help.kickstarter.com/en-us/articles/16236428-what-are-the-rules-for-hardware-and-product-design-projects). Recheck current rules before submitting a campaign.

## AI assistance in this CAD release

Codex assisted with drafting the parametric CAD source, documentation, technical previews and validation checks under the project owner's direction. The owner selected the R4 layout and supplied the component measurements. Technical previews are rendered from CAD, with a neutral display surface by default; they are not photographs. An optional legacy UI illustration is included for orientation only and does not demonstrate released software.

The source and recorded geometry checks can be inspected, but neither AI assistance nor computational checks establish physical fit, sensing accuracy, acoustics or camera performance. Those require the tests described in the print instructions. Any later campaign using AI features or synthetic media must disclose the actual architecture, human contribution, provider dependencies and relevant rights accurately. This project does not claim to have trained its own model or verified a provider's training-data rights.
