# Wyatt roadmap

This is a sequence of validation gates, not a delivery schedule.

1. **Print and fit R4.** Run all coupons, actual port/tool and camera checks, then the complete enclosure. Record speaker retention/excursion, seal compression, sensor thermal bias and desk stability. Revise measured failures before treating the design as fitted.
2. **Release the full DIY build after validation.** Publish reproducible firmware/backend source, hardware wiring, setup and recovery instructions, licenses and current test evidence. State which functions run on the board, a local computer or a paid cloud provider. Keep optional camera use deliberate and documented.
3. **Evaluate assembled, tested Wyatt units.** Establish a repeatable assembly/test process, actual manufacturing cost, support approach and applicable market requirements. Price, availability and shipping regions remain to be decided.
4. **Prepare a campaign from a working prototype.** Show real hardware and actual demonstrated functions, with realistic costs and delivery assumptions. Kickstarter URL is pending; this release does not announce a live campaign.

We welcome improvements that preserve the selected single horizontal form, serviceability, clear camera/microphone openings and isolated room-sensor air path. Measured build reports are especially useful. See [contributing](../CONTRIBUTING.md).
